Large videos (not part of any skill bundle; nothing here is needed to build an episode).

- `character-clips/`: original Professor/Emily videos with their background:
  - walk and idle loops (`walkP`, `walkE`, `idleP`, `idleE`)
  - ElevenLabs lip-sync clips (`lsC1`–`lsC7`, `lsCE`)

  Use these only to re-cut the characters (`pixar-classroom-hybrid-3d/python/cut_sprites.py`) or to recalibrate lip sync. The skills already contain the cut-outs.
- `episodes/`: full-size approved episodes (Episode 4, Episode 3 v3), for viewing only. Files over 100 MB go in a GitHub Release, not in git.
