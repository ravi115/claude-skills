# Universe look (3D middle)

Approved on 2026-11-17 (LLM-GPT2 Episode 4 test). Reference clip: `references/universe/videos/approved_universe_glass_30s.mp4`. Stills: `references/universe/photos/`.

`Universe.jsx` holds everything for this look, and `World3D.jsx` imports it:
- `UniverseSky`: the night-black sky texture (warm glowing stars, a very faint Milky Way), the nine planets (`PLANETS`) and the sun light.
- `GlassFloor`: the dark glass deck with frosted seams and the starfield underneath.
- `setUniverseT0`: World3D calls this with the middle of the 3D section, so planet motion is centred there.

To use it, set `"look": "universe"` in episode.json. It is the default, so leaving `look` out gives the same result. `"look": "teal"` brings back the Episode 5 sky and grid.

Do not edit this file per episode.
